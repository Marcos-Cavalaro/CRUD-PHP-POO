CRUD PHP POO

Sistema CRUD desenvolvido em PHP utilizando Programação Orientada a Objetos (POO), com operações de cadastro, listagem, edição e exclusão de registros.

📋 Sobre o Projeto

Este projeto tem como objetivo demonstrar a implementação de um CRUD completo utilizando:

-PHP Orientado a Objetos;
-MySQL;
-PDO para conexão com banco de dados;
-Estrutura organizada em classes;
-Boas práticas de desenvolvimento.

🚀 Funcionalidades
✅ Cadastro de registros;
✅ Listagem de dados;
✅ Atualização de informações;
✅ Exclusão de registros;
✅ Conexão segura com PDO;
✅ Organização em MVC simples;

🛠️ Tecnologias Utilizadas
PHP 8+;
MySQL;
HTML5;
CSS3;
Bootstrap (opcional).
